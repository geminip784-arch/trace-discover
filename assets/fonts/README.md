# Fonts

Served from this folder only; the app never loads fonts from another site.

- `fredoka-latin-600-normal.woff2`: Fredoka SemiBold, Latin letters and digits.
  From the npm package `@fontsource/fredoka` 5.3.0. Licence: SIL Open Font
  License 1.1, in `OFL.txt`.
- `noto-naskh-arabic-arabic-400-normal.woff2` and
  `noto-naskh-arabic-arabic-700-normal.woff2`: Noto Naskh Arabic, Regular and
  Bold, Arabic-script letters (all 39 Urdu letters on the Urdu board). Bold is
  the Urdu tiles' font (`index.html`); Regular is the faint comparison letter on
  `glyphs.html` (Slice 10A). From the npm package
  `@fontsource/noto-naskh-arabic` 5.3.0. Licence: SIL Open Font License 1.1, in
  `OFL-noto-naskh-arabic.txt`.
