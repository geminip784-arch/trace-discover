# Urdu letters — review screenshots

Taken in headless Chromium at 1280 px wide (2x), from `glyphs.html`.

| File | What it shows |
|---|---|
| `samples.png` | Slice 10A: the six sample letters ا ب ج د ع ے, filling from the right, drawn with smooth curves from `data/glyphs.js` (`URDU_GLYPHS`). Each sits on the four lines (the grass line is the Urdu baseline) over the faint purple Noto Naskh Arabic letter it follows. Numbered dots mark where each stroke starts (1 blue, 2 amber, 3 green); arrows show its direction; a dot is a tap, its number sitting on it. Dashed cards are the other allowed plan of ج and ع: the head, then the tail. |
